# Kalkulator UMKM

Aplikasi sederhana untuk usaha kecil: modal per pcs, harga jual, target jualan aman, catatan jualan harian dengan untung harian, stok bahan, biaya, dan untung bulanan.

- Data tersimpan di HP (tidak dikirim ke mana pun).
- Bisa dibuka tanpa internet setelah dibuka sekali, dan bisa dipasang ke layar utama HP.
- Rumus ada di `calc.js`. Uji rumus: `node tests/calc.test.js`.
